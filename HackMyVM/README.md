# HackMyVM

HackMyVM is a cybersecurity platform that provides vulnerable virtual machines and challenges for practicing penetration testing, Linux, enumeration, privilege escalation, and other cybersecurity skills.

This directory contains my personal write-ups, notes, and practical learning experiences from HackMyVM challenges.

## What I Practice

* Linux fundamentals
* Enumeration
* Privilege escalation
* Vulnerability identification
* Web and network security
* Scripting and automation
* CTF problem-solving
* Practical cybersecurity techniques

## Write-ups

Each machine or challenge is organized separately, with the steps, commands, techniques, and lessons learned documented along the way.

> Flags, passwords, and other challenge answers may be redacted from the write-ups.
